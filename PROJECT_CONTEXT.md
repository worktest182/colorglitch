# ColorGlitch — Project Context (Stage 3 Stabilization)

## 🎯 Цель проекта
Интерактивный инструмент подбора цвета стен в интерьере.

Пользователь:
- выбирает цвет
- включает warm / cool освещение
- видит предсказуемое изменение оттенка
- использует как инструмент колеровки краски

---

## ⚙️ Главный принцип системы

❗ Это НЕ физический симулятор света

Это UX-инструмент визуального подбора цвета.

Приоритеты:
1. предсказуемость
2. заметный эффект
3. стабильность
4. одинаковое поведение на всех цветах

---

## 🌈 Chromatic Pipeline (упрощённая модель)

### Основное правило изменения оттенка:

```js
h: hsl.h + (state.lighting === 'warm' ? -6 : 6)
```

---

### Ограничения:

- saturation shift: ±0.03 максимум
- lightness shift: ±0.02 максимум
- intensity НЕ должен ломать цвет

---

## ⚪ Achromatic colors (белый / почти белый)

Если цвет близок к белому:

```js
rgb.r >= 245 && rgb.g >= 245 && rgb.b >= 245
```

➡ вернуть цвет БЕЗ любых HSL трансформаций

```js
return baseColor;
```

---

## 💡 Lighting behavior

### Warm:
- hue -6
- лёгкое затемнение (минимальное)

### Cool:
- hue +6
- лёгкое осветление (минимальное)

---

## ❌ ЗАПРЕЩЕНО

Удалить / не использовать:

- getHueShift()
- getSaturationShift()
- intensity-driven distortion
- anti-green logic
- сложные perceptual модели
